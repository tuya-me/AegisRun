# AegisRun Documentation Guide

> v0.8.0

---

## Structure

```
README.md                    ← Project overview (Chinese)
docs-ch/                      ← Chinese docs (primary)
docs-en/                      ← English docs (auxiliary)
```

## Conventions

| Rule | Standard |
|------|----------|
| Language | Chinese primary, English auxiliary |
| Chinese docs | `docs-ch/` |
| English docs | `docs-en/` |
| Filenames | English (GUIDE.md) |
| Sensitive info | Excluded from repo |
