## Structure

```
README.md                    ← Project overview (Chinese)
docs-ch/                      ← Chinese docs (primary)
docs-en/                      ← English docs (auxiliary)
```

## Conventions

| Rule | Standard |
|------|----------|
| Language | Chinese primary, English auxiliary |
| Chinese docs | `docs-ch/` |
| English docs | `docs-en/` |
| Language switch | Link at top of each page |
| Filenames | English (GUIDE.md) |
| Sensitive info | Excluded from repo |

## Language Link Format

Each Chinese page links to English:
```markdown
> 🇬🇧 [English version →](docs-en/FILENAME.md)
```

Each English page links to Chinese:
```markdown
> 🇨🇳 [中文版 →](docs-ch/FILENAME.md)
```
