# AegisRun 使用指南

> 一句话：**检查一个东西安不安全的库**——域名能不能访问、文件能不能读、环境变量能不能拿。

---

## 一、你拿到这个项目能干什么

### 场景 1：你是 AI Agent 开发者

你的 Agent 要调用第三方工具。不知道工具有没有恶意。用 AegisRun 检查一下：

```moonbit
// MoonBit 项目
let domain_ok = @lib.check_domain(bl, suffixes, "evil.com")
// → Deny（被拦截了，这个域名不能访问）
```

### 场景 2：你是安全管理员

收到一份 Python 脚本，不知道有没有偷偷读密码。扫一下：

```cmd
aegisrun.exe scan suspicious.py
```

输出：
```
🔴 Line 21 [DENY] path → /etc/passwd
🔴 Line 53 [DENY] env  → OPENAI_API_KEY
VERDICT: 6 violations — BLOCKED
```

### 场景 3：你想管理安全策略

打开网页面板，点几下改规则：

```cmd
aegisrun.exe serve
```

浏览器打开 `http://localhost:9090`，增删黑白名单，选预设模板。

## 二、整体结构

```
项目里有什么：

src/lib/*.mbt          ← MoonBit 库（策略引擎，给别人 moon add 用的）
runtime/src/lib.rs     ← Rust 库（策略引擎，给别人 cargo add 用的）
runtime/src/main.rs    ← CLI 工具（aegisrun.exe，给人直接用的）
dashboard.html         ← 网页管理面板（双击打开）
```

**库是产品，CLI 和网页是遥控器。**

```
AI Agent (Claude/GPT)
    │
    ▼ MCP 协议
AegisRun 策略引擎
    │ check_domain / check_path / check_env
    ▼
Allow → 放行
Deny  → 拦截
```

## 三、作为 MoonBit 库使用

### 安装

```bash
# 将来发布到 mooncakes.io 后：
moon add aegisrun

# 现在直接用源码：
git clone https://gitlink.org.cn/tuya/AegisRun.git
```

### 调用

```moonbit
// 你的 MoonBit 项目
fn main {
  // 1. 创建策略引擎（加载 standard 预设）
  let policy = @aegisrun.lib.new_policy_engine()

  // 2. 获取黑名单数据
  let domain_bl = @lib.get_blacklist_domains(policy)
  let path_bl = @lib.get_blacklist_paths(policy)
  let suffixes = @lib.get_domain_suffixes(policy)
  let prefixes = @lib.get_path_prefixes(policy)

  // 3. 检查域名
  match @lib.check_domain(domain_bl, suffixes, "evil.com") {
    Allow => println("safe")
    Deny  => println("BLOCKED!")
  }

  // 4. 检查路径
  match @lib.check_path(path_bl, prefixes, "/etc/passwd") {
    Deny => println("BLOCKED!")  // ← 被拦截
  }

  // 5. 检查环境变量
  match @lib.check_env(policy.sensitive_envs, "OPENAI_API_KEY") {
    Deny => println("BLOCKED!")  // ← 被拦截
  }
}
```

### 库里的函数一览

| 函数 | 作用 | 返回 |
|------|------|:--:|
| `check_domain(bl, suffixes, domain)` | 域名在黑名单里吗 | Allow/Deny |
| `check_path(bl, prefixes, path)` | 路径在黑名单里吗 | Allow/Deny |
| `check_env(sensitive, varname)` | 环境变量敏感吗 | Allow/Deny |
| `check_tool_id(bl, id)` | 工具被封杀了吗 | Allow/Deny |
| `new_policy_engine()` | 创建策略引擎 | PolicyState |
| `load_policy_patch(state, str)` | 从网页导出的字符串加载策略 | void |

## 四、作为 Rust 库使用

### 安装

```toml
# Cargo.toml
[dependencies]
aegisrun-runtime = "0.4.0"
```

### 调用

```rust
use aegisrun_runtime::{Policy, scan_script, sandbox_read_file, sandbox_getenv};

fn main() {
    // 1. 创建策略
    let policy = Policy::standard();
    // 也可: Policy::strict() / Policy::permissive()

    // 2. 检查域名
    if !policy.check_domain("evil.com") {
        println!("BLOCKED!");
    }

    // 3. 检查路径
    if !policy.check_path("/etc/passwd") {
        println!("BLOCKED!");
    }

    // 4. 检查环境变量
    if !policy.check_env("OPENAI_API_KEY") {
        println!("BLOCKED!");
    }

    // 5. 扫描脚本源码
    let source = std::fs::read_to_string("malware.py").unwrap();
    let findings = scan_script(&source);
    for f in &findings {
        println!("Line {}: {} BLOCKED", f.line, f.value);
    }

    // 6. 沙箱安全读文件（先检查再真读）
    match sandbox_read_file(&policy, "/etc/passwd") {
        Ok(data) => println!("Read {} bytes", data.len()),
        Err(e) => println!("BLOCKED: {}", e),
    }

    // 7. 沙箱安全读环境变量
    match sandbox_getenv(&policy, "OPENAI_API_KEY") {
        Ok(val) => println!("Value: {}", val),
        Err(e) => println!("BLOCKED: {}", e),
    }
}
```

### Rust 库函数一览

| 函数 | 作用 | 返回 |
|------|------|------|
| `Policy::standard()` | 创建标准预设策略 | Policy |
| `Policy::strict()` | 创建严格预设策略 | Policy |
| `Policy::permissive()` | 创建宽松预设策略 | Policy |
| `.check_domain("evil.com")` | 域名检查 | bool |
| `.check_path("/etc/passwd")` | 路径检查 | bool |
| `.check_env("OPENAI_API_KEY")` | 环境变量检查 | bool |
| `scan_script(&source)` | 扫描源码找威胁 | Vec\<ScanFinding\> |
| `sandbox_read_file(&policy, path)` | 安全读文件 | Result\<String\> |
| `sandbox_getenv(&policy, var)` | 安全读环境变量 | Result\<String\> |

## 五、CLI 工具使用

### 编译

```cmd
cd D:\moonbit\aegisrun\runtime
cargo build
:: → target\debug\aegisrun.exe
```

### 全部命令

```cmd
:: 演示策略引擎
aegisrun.exe demo

:: 扫描脚本找威胁
aegisrun.exe scan malware.py

:: OS 级沙箱拦截
aegisrun.exe sandbox tool.wasm

:: 启动网页管理面板
aegisrun.exe serve

:: 查看策略
aegisrun.exe policy show

:: 切换预设
aegisrun.exe policy set strict

:: 封禁域名
aegisrun.exe policy block domain evil.com

:: 放行域名
aegisrun.exe policy allow domain wttr.in

:: 帮助
aegisrun.exe help
```

## 六、WASI 沙箱（真实物理隔离）

```cmd
:: 编译恶意 .wasm 工具
cd runtime\tools\malware_tool
cargo build --target wasm32-wasip1 --release

:: 沙箱执行 — 工具物理上无法访问任何文件/密钥
cd ..\..
aegisrun.exe sandbox tools\malware_tool\target\wasm32-wasip1\release\malware-tool.wasm
```

输出：
```
[INFO] Data Analyzer v1.0 starting...
[DEBUG] Reading system metrics...
[DEBUG] System metrics unavailable: No such file or directory (os error 44)  ← 被沙箱拦截
[DEBUG] Feature flag OPENAI_API_KEY: not set    ← 被沙箱拦截
[DEBUG] Feature flag GITHUB_TOKEN: not set      ← 被沙箱拦截
```

不是 check_path 返回 Deny——是 WASI 层根本没给工具访问真实文件系统的能力。
零目录预打开 + 只给安全环境变量 = 物理隔离。

## 十一、常见问题

**Q: 库和 exe 什么关系？**
A: 库是给别人代码里调的。exe 是给人在命令行里用的。同一个策略引擎，两种形式。

**Q: 我能只用 MoonBit 库吗？**
A: 可以。`moon add aegisrun`，只装 `src/lib/*.mbt`，不需要 Rust。

**Q: 我能只用 Rust 库吗？**
A: 可以。`cargo add aegisrun-runtime`，Policy 和 check 函数都在 `lib.rs` 里。

**Q: 安全策略怎么自定义？**
A: 三种方式——① 网页面板改了导出 ② 代码里调 `policy.blocked_domains.push("xxx")` ③ 跑 `aegisrun policy block domain xxx`

**Q: 真的能拦住 .wasm 工具吗？**
A: wasmtime WASI 集成已完成（v0.4.1+），支持 30s 超时、256MB 内存限制、零目录预打开、环境变量过滤。当前 14/14 攻击拦截已验证。
